# BERT vs GPT vs T5 Model Selection for HR Automation

### 📌 Project Overview
A Generative AI-based project that compares BERT, GPT, and T5 Transformer models for automating Human Resource (HR) activities.

### 🎯 Objectives
- Compare the capabilities of BERT, GPT, and T5.
- Automate HR tasks such as resume classification, skill extraction, and summarization.
- Evaluate models based on accuracy, precision, recall, F1-score, and response time.
- Identify the most suitable model for different HR requirements.

### 🤖 Models Used
- **BERT:** Text classification and skill extraction.
- **GPT:** HR chatbot and content generation.
- **T5:** Resume summarization and text transformation.

### 🛠️ Technologies
Python | NLP | Generative AI | Transformers | Machine Learning

### 📊 Expected Outcome
A comparative model-selection framework that identifies the most suitable AI model for different HR automation tasks.
